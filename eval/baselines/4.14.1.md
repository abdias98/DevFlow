## 2. Run scorecards — see 4.14.0

Twelve blind runs (one `/devflow-feature` and one bare per task) are recorded in
[`4.14.0.md`](./4.14.0.md) §2, artifacts under [`runs/4.14.0/`](./runs/4.14.0/).
All twelve score 100% outcome.

**Calibration is not a run result.** A naive reference scoring 76–83% proves the
checks can tell implementations apart. It does not mean a bare run of a capable
model produces one: none of the six bare runs did.

## 3. What is still unknown

- Whether DevFlow changes an outcome on tasks a bare run of the same model does
  *not* already pass — no such task exists yet.
- Whether it does with a weaker model — only one model was run.
- Run-to-run variance — one run per cell.
- Whether escape analysis and runtime verification (4.14.0) do anything — no task
  or real cycle has exercised them.
