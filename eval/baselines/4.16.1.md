## 3. What this means for earlier scorecards

Every `/devflow-feature` run recorded so far (4.12.0, 4.14.0) used an install
that told the agent to use VS Code tool names (`create_file`,

are unaffected. They still ran with instructions that named missing tools. A
future comparison should note which side of 4.16.1 its install was on.
